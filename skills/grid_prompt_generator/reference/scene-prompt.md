# 场景图片提示词模板

## 模板结构

```
空场景资产图，用于后续多模态视频生成的场景参考。[location]，[time]。
空间结构和方向保持稳定：[入口/出口/墙面/主要家具或陈设的位置关系]。
环境细节：[architecture/materials/objects/lighting/color palette/atmosphere/camera feeling]。
Style: [art style], cinematic quality, high quality, consistent art style.
空场景，不出现人物，不出现剧情动作，不出现临时剧情道具，不出现文字、字幕、Logo、水印或 UI。
```

## 示例

```
空场景资产图，用于后续多模态视频生成的场景参考。公寓电梯内部，清晨。
空间结构和方向保持稳定：正前方是电梯门，左右两侧为金属镜面墙，顶部冷白灯，楼层数字屏位于门上方，地面干净微反光。
环境细节：狭窄金属轿厢，冷白光，轻微压抑的通勤氛围，平视中景可拍摄，镜面能反射人物上半身。
Style: realistic short-drama cinematic quality, high quality, consistent art style.
空场景，不出现人物，不出现便利贴、手机、饭盒等临时剧情道具，不出现文字、字幕、Logo、水印或 UI。
```
