# 分镜拆解指南

## 拆解原则

每个分镜不是剧情摘要，而是一次 AI 视频生成任务。每个镜头聚焦**单一主要动作目标**，允许同一目标下少量连续动作，描述要详尽具体。普通 AI 视频镜头 duration 优先 6-10 秒；低运动、情绪停顿或对话反应可 10-15 秒；过渡镜头可 4-6 秒；所有 duration 必须是 4-15 的整数。

- 单镜头只允许一个连续空间、一个主要动作目标、一种镜头运动；起始画面和结束画面必须能用同一个场景参考图生成
- 角色跨过门、电梯门、玻璃门，或地点从厨房/玄关/电梯/大厅/室外/会议室切换时，必须新开镜头
- 单镜头最多承载一个关键道具状态变化，例如饭盒塞入包、便利贴掉出、手机来电、文件被推回；超过一个就拆镜
- 需要观众看清的文字、来电、纸条、合同、诊断、聊天记录，优先拆成近景或特写，不要塞进中景大动作里
- 如果一个镜头包含“发现 → 反应 → 离开/转场”三个剧情功能，必须拆成 2-3 个镜头
- 不要为了“衔接完整”额外补纯反应镜头或重复环境镜头；但如果前后镜不能直接剪，必须新增 1 个 4-6 秒过渡镜头，展示门关、电梯数字、走到玻璃门、撑伞等可见桥接动作

## 镜头要素

1. **镜头标题**：4-8字概括核心内容（如"噩梦惊醒"）
2. **时间**：具体时分 + 光线描述
3. **地点**：场景完整描述 + 空间布局 + 环境细节
4. **景别**：远景/全景/中景/近景/特写
5. **角度**：平视/仰视/俯视/侧面/背面
6. **运镜**：固定/推镜/拉镜/摇镜/跟镜/移镜
7. **动作**：谁 + 具体怎么做 + 肢体细节 + 表情
8. **对话**：该镜头的完整对话
9. **画面结果**：动作的即时后果 + 视觉细节
10. **氛围**：光线 + 色调 + 声音 + 整体氛围
11. **时长**：普通镜头 6-10 秒，低运动镜头 10-15 秒，过渡镜头 4-6 秒，且必须是 4-15 的整数
12. **静态画面提示词**：`image_prompt` 为共同视觉基底；`first_frame_prompt` / `last_frame_prompt` 分别描述动作前后的可见状态
13. **视频提示词**：`video_prompt`，使用 Seedance 2.0 分秒时间轴描述镜头动作与多模态素材绑定（必填）
14. **配乐提示词**：`bgm_prompt`，描述该镜头适合的配乐风格
15. **音效提示词**：`sound_effect`，描述该镜头关键环境音/动作音
16. **场景关联**：若能匹配已有场景，必须填写 `scene_id`
17. **角色关联**：填写 `character_ids`，绑定当前镜头涉及的 0 到多个角色
18. **衔接包**：填写 `transition_in / transition_out / screen_direction / audio_bridge / negative_prompt / fallback_plan / handle_in_ms / handle_out_ms`

## 视频提示词格式

每个镜头必须包含 `video_prompt` 字段，用于驱动 AI 视频生成：

```
参考素材绑定：人物参考：小明，仅参考面部、发型、服装和体态；场景参考：咖啡厅，仅参考室内空间、光线和桌椅布局；如有上一镜头截帧，它只是上一镜头截帧/首图衔接参考，不替代人物图和场景图。
主体与场景：小明独自坐在咖啡厅靠窗座位，午后，环境安静。
入场与首帧：近景，小明低头看手机，肩膀紧绷；0.6 秒入场把手内保持姿态，仅有自然呼吸。
分秒时间轴：0.0-0.6秒：保持首帧；0.6-2.8秒：拇指停在屏幕上；2.8-5.6秒：屏幕暗下，他停顿后缓慢抬眼；5.6-7.4秒：视线转向画外右侧门口；7.4-8.0秒：稳定保持尾帧。
运镜与画面：固定近景，始终在咖啡厅内，不切到门外，不改变景别，视线轴保持画面右侧。
出场与尾帧：小明仍坐在桌边，手机停在掌心，视线转向门口；尾帧保持 0.6 秒，下一镜可从门口动静承接。
声音与对白：咖啡厅底噪连续，手机提示音一次，无对白。
画质与风格：高清，真实短剧电影感，色彩自然，光线稳定，人物面部和服装保持一致，动作低缓连续。
约束与禁止项：不要提前让小红坐下，不要切换到门外，不要新增旁观者；不要生成字幕、Logo、水印或 UI；不要生成同款分身；不要让角色图和场景图互相混用。
失败降级：若拇指与屏幕交互不稳定，改为手掌轻握手机；尾帧视线和剧情结果不变。
```

视频提示词不要使用 `<role>`、`<location>` 或 `<voice>` 这类 XML 标签；角色名、场景名、说话人都用自然中文直接写清楚。

## 使用步骤

1. 调用 `read_storyboard_context` 读取剧本、角色、场景、已有分镜摘要
   - `existing_storyboards` 只作为当前剧本片段之前紧邻的连续性锚点；只读取最后一镜的 `result`、人物位置、场景与道具状态并从那里承接，不要复述或重新生成这些锚点
2. 先基于剧本完成镜头拆解，确保总时长和叙事连续性合理
3. 每个镜头写入 JSON 前，完成起始状态、结束状态、下一镜头承接点、禁止提前动作四项边界判断，并分别写入首帧、尾帧、入场、出场和禁止项字段
4. 为每个镜头补全完整字段：`title / shot_type / angle / movement / location / time / character_ids / action / dialogue / description / result / atmosphere / image_prompt / first_frame_prompt / last_frame_prompt / video_prompt / transition_in / transition_out / screen_direction / audio_bridge / negative_prompt / fallback_plan / handle_in_ms / handle_out_ms / bgm_prompt / sound_effect / duration / scene_id`
5. 调用 `save_storyboards` 一次性保存完整分镜
6. 如需调整，调用 `update_storyboard` 修改具体镜头

## 场景关联规则

- 优先使用 `read_storyboard_context` 返回的 `scenes`
- `location + time` 可明确匹配时，必须回填正确 `scene_id`
- 不要凭空生成不存在的场景 ID
- 如果剧本内容明显落在已有场景中，不要重复创造新场景描述

## 角色绑定规则

- `character_ids` 必须从 `read_storyboard_context` 返回的角色列表中选择
- 一个镜头可以没有角色，也可以绑定多个角色
- 只要镜头里有明确出场、被看见、发生动作或说话的角色，都应绑定进去
- 标题、描述、动作、对白、`image_prompt` 或 `video_prompt` 中明确点名，且被看向、被对话指向、被他人反应或作为画面焦点的当前集角色，也必须绑定，即使他不是该镜头的主动动作主体
- 纯环境镜头、空镜头、物件镜头可以传空数组

## 质量要求

- `description` 要适合人读，`video_prompt` 要适合模型生成，二者不要互相替代
- 上下镜头必须遵循“上一镜结束画面 = 下一镜起始画面的可见前因”；观众应能从上一镜最后一帧理解下一镜第一帧为什么出现
- 每个镜头必须设计入点和出点：分别写入 `transition_in` 与 `transition_out`；首尾可见状态分别写入 `first_frame_prompt` 与 `last_frame_prompt`
- 如果两个镜头之间发生位置变化，必须满足两种情况之一：上一镜 `result` 已明确给出离开动作；或新增过渡镜头展示可见桥接动作
- 不允许用一句“随后”“转眼”“来到”跳过关键物理动作
- 如果饭盒、便利贴、手机、文件等连续线索跨镜出现，必须保持状态连续：在谁手里、在哪个包里、是否露出、是否被夹进文件
- `image_prompt` 是共同视觉基底；首帧写动作前状态，尾帧写动作后的稳定落点，二者保持人物、服装、轴线、光线和道具一致
- `video_prompt` 必须包含参考素材绑定、主体与场景、入场与首帧、分秒时间轴、运镜与画面、出场与尾帧、声音与对白、画质与风格、约束与禁止项、失败降级
- 分镜阶段不要假定最终素材编号，也不要把“图片1=人物图、图片2=场景图”写死；参考素材绑定只写素材分工意图；多人物时必须逐个写清“人物参考：林晚、林建国”，不要只写笼统“人物参考”；如有上一镜头截帧，只写它是“上一镜头截帧/首图衔接参考”，不是人物图或场景图；最终生成视频时，系统会按实际上传顺序自动补充图片1、图片2、图片3等编号
- 分秒时间轴必须从 0.0 秒连续覆盖到 `duration`，无空档、无重叠；第一段和最后一段分别覆盖 `handle_in_ms` 与 `handle_out_ms`，推荐各 500-800 毫秒；不要再使用“动作阶段1/2/3”
- 如果 `action`、`description` 与 `result` 冲突，以 `result` 的结束画面为准；不要提前完成下一镜头才应发生的动作
- 约束中必须写明不要生成字幕、Logo、水印或 UI，不要生成同款分身，不要把角色图、场景图、动作参考或音频参考互相混用
- `bgm_prompt` 和 `sound_effect` 用简洁短语即可，但不能空泛到只有“紧张”“悲伤”
- 若存在旁白，统一写入 `dialogue`，格式为 `旁白：内容`
- 自检时确认：上一镜最后一帧与下一镜第一帧能不能直接剪；如果不能直接剪，是否需要新增 1 个 4-6 秒过渡镜头
