# 个人主页与充值页前端设计

## 设计读法

这是面向已登录创作者的账户与资金工作台，不是营销页。界面沿用 AiDrama 现有浅色工作台语言：冷蓝强调色、8px 圆角、lucide 图标、紧凑可扫描的信息密度、克制动效。

## 页面范围

- `/profile`：个人主页，展示账户、余额、项目概览、待结算提醒和最近资金动态。
- `/wallet`：充值页，展示余额、支付宝充值、订单、流水和待结算视频。
- 视频创作页：在生成按钮、轮询状态、结果区展示实时扣费和余额不足状态。

## 信息架构

### 个人主页

首屏展示：

- 用户信息：用户名、手机号、账号状态。
- 当前余额：两位小数，单位为元。
- 当前视频单价：例如 `1.00 元/秒`。
- 待结算提醒：存在 `billing_required` 视频时显示。
- 创作概览：项目数、生成中视频、本月消耗、累计扣费秒数。
- 最近动态：充值订单和扣费流水混排。
- 快捷入口：充值、项目工作台、形象库、设置。

### 充值页

页面分区：

- 余额卡：当前余额、累计充值、累计消耗、视频单价。
- 充值表单：金额输入必须是两位小数字符串，快捷金额为 `10.00`、`50.00`、`100.00`、`500.00`。
- 订单状态：从支付宝返回后轮询订单，异步通知到账后刷新余额。
- 列表区：订单、流水、待结算视频三个标签页。

### 视频实时扣费

视频生成区展示：

- 当前视频单价。
- 已确认秒数。
- 已扣金额。
- 结算状态。
- 余额不足时显示充值和重试结算入口。

不展示预估总价，不做预扣提示。

## 状态文案

- `pending`：等待支付。
- `paid`：已到账。
- `failed`：支付失败。
- `closed`：订单已关闭。
- `billing_required`：余额不足，充值后可继续结算。
- `settled`：已结算。
- `billing_failed`：结算失败。

## 视觉约束

- 主题锁定为现有浅色工作台。
- 主要强调色继续使用现有 `--accent`。
- 页面主卡片、按钮、输入框使用现有 `--radius`。
- 不使用营销页 hero、装饰性滚动提示、假数据精确指标。
- 所有金额展示为两位小数。
